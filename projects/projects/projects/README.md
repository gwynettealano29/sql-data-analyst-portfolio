# Subscription Services Analysis using SQL

## Project Overview
This beginner SQL project explores subscription service records using MySQL. It demonstrates basic data retrieval, filtering, and sorting techniques.

## Dataset
The sample dataset contains 8 fictional subscription service records with the following fields:

- `solution_id` — unique identifier for each solution
- `solution_name` — name of the service
- `status` — active or cancelled
- `monthly_fee` — monthly service fee

## Business Questions
1. What subscription services are listed in the dataset?
2. Which services are active?
3. Which services have been cancelled?
4. Which active services have a monthly fee above 3,000?
5. Which services have the highest monthly fees?

## SQL Skills Demonstrated
- SELECT
- WHERE
- AND
- ORDER BY
- DESC
